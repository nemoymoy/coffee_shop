# Реализация 152-ФЗ "О персональных данных" — Coffee Shop

## Цель
Добавить сбор согласия на обработку персональных данных при регистрации с чекбоксом (не отмеченным по умолчанию) и отдельной таблицей для хранения подтверждений.

## Сбор ПД в проекте

**Форма регистрации** (`UserRegistrationForm`) собирает 4 поля персональных данных:
| Поле | Описание |
|------|----------|
| `username` | Имя пользователя |
| `email` | Email адрес |
| `first_name` | Имя |
| `last_name` | Фамилия |

## Архитектурное решение

### 1. Модель согласия: `PersonalDataConsent`

**Файл:** `django/coffee_shop/apps/users/models/personal_data_consent.py`

```python
class PersonalDataConsent(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='consents')
    # Версия согласия (для будущих изменений текста)
    version = models.CharField(max_length=10)
    # Текст-хэш актуального текста согласия (для аудита)
    content_hash = models.CharField(max_length=64)
    # Дата предоставления согласия
    consented_at = models.DateTimeField(auto_now_add=True)
    # IP-адрес для аудита
    ip_address = models.GenericIPAddressField(null=True, blank=True)
    # Юзер-агент
    user_agent = models.TextField(blank=True, default='')

    class Meta:
        ordering = ['-consented_at']
        indexes = [models.Index(fields=['user', 'version'])]
```

### 2. Форма регистрации: обязательное поле `personal_data_consent`

**Файл:** `django/coffee_shop/apps/users/forms/registration_form.py`

- Добавить поле `personal_data_consent = forms.BooleanField(required=True, error_messages={'required': 'Необходимо дать согласие на обработку персональных данных.'})`
- Без виджета CheckboxInput — поле будет рендериться вручную в шаблоне
- Валидация на бэкенде через форму (`is_valid()`)

### 3. Вид регистрации: создание записи согласия

**Файл:** `django/coffee_shop/apps/users/views.py`

- При успешной валидации формы (`form.is_valid()`):
  1. Сохранить пользователя (`form.save()`)
  2. Создать запись `PersonalDataConsent` с `ip_address = request.META.get('REMOTE_ADDR')` и `user_agent = request.META.get('HTTP_USER_AGENT', '')[:1000]`

### 4. Шаблон регистрации: чекбокс + ссылка на текст

**Файл:** `django/coffee_shop/templates/users/register.html`

- Добавить чекбокс **перед** кнопкой "Зарегистрироваться":
```html
<div class="mb-3">
    <div class="form-check">
        <input type="checkbox" name="personal_data_consent" id="personal_data_consent" class="form-check-input" required>
        <label class="form-check-label" for="personal_data_consent">
            Я даю согласие на обработку персональных данных
            в соответствии с <a href="{% url 'users:personal_data_consent_text' %}" target="_blank">Политикой обработки персональных данных</a>
        </label>
    </div>
</div>
```
- Фронтенд-валидация через `required` атрибут + JS-валидация
- Прямая ссылка на `users:personal_data_consent_text`

### 5. View для отображения текста согласия

**Файл:** `django/coffee_shop/apps/users/views.py` (или отдельный `consent_views.py`)

```python
def personal_data_consent_text_view(request):
    """Отображение текста согласия на обработку ПД."""
    return render(request, 'users/personal_data_consent_text.html')
```

### 6. Текст согласия

**Файл:** `django/coffee_shop/templates/users/personal_data_consent_text.html`

Документ с текстом согласия, учитывающим конкретные ПД проекта:
- username (имя пользователя)
- email (электронная почта)
- first_name (имя)
- last_name (фамилия)
- IP-адрес (собирается автоматически)
- User-Agent (собирается автоматически)

Включает:
- Цели обработки (регистрация, авторизация, оформление заказов, коммуникация)
- Перечень ПД
- Правовые основания (152-ФЗ, ст. 6, п. 1 ч. 8 — согласие субъекта)
- Срок действия согласия
- Порядок отзыва согласия
