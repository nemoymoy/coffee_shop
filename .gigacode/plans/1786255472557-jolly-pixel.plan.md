### 1. Исправить импорт ProductForm
**Файл:** `django/coffee_shop/apps/catalog/forms/product_form.py`
- Класс `ProductFilterForm` → переименовать в `ProductForm`

### 2. Исправить `is_active` в views.py
**Файл:** `django/coffee_shop/apps/catalog/views.py`
- Убрать `is_active` из `Product.objects.filter()` — поле не существует в модели Product
- Было: `Product.objects.filter(is_active=True, is_available=True)`
- Стало: `Product.objects.filter(is_available=True)`

### 3. Добавить поле user в миграцию Review
**Файл:** `django/coffee_shop/apps/catalog/migrations/`
- Создать миграцию `0002_review_user.py` с `AddField` для `user = ForeignKey(AUTH_USER_MODEL)`

### 4. Заполнить serializers.py
**Файл:** `django/coffee_shop/apps/catalog/serializers.py`
- `CategorySerializer` — id, name, slug, parent, children, is_active
- `ProductSerializer` — полная карточка товара с вложенными category
- `ReviewSerializer` — rating, comment, is_approved с read-only user
