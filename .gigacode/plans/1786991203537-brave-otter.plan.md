# Яндекс OAuth 2.0 — Реализация авторизации

## Обзор
Реализовать вход/регистрацию через Яндекс OAuth для существующего Django-проекта. Используются встроенные модели Django (`User`) — кастомная модель пользователя отсутствует.

## Подход
Используем `social-auth-app-django` — стандартный пакет для Social Auth в Django.

## Шаги реализации

### 1. Зависимости
**Файл:** `requirements/base.txt`
- Добавить `social-auth-app-django==4.4.2`

### 2. Настройки Django
**Файл:** `django/coffee_shop/settings/base.py`

Добавить:
```python
# Yandex OAuth 2.0 (User Authentication)
YANDEX_OAUTH_CLIENT_ID = os.environ.get('YANDEX_OAUTH_CLIENT_ID', '')
YANDEX_OAUTH_CLIENT_SECRET = os.environ.get('YANDEX_OAUTH_CLIENT_SECRET', '')
YANDEX_OAUTH_AUTHORIZATION_URL = 'https://oauth.yandex.ru/authorize'
YANDEX_OAUTH_TOKEN_URL = 'https://oauth.yandex.ru/token'
YANDEX_OAUTH_PROFILE_URL = 'https://login.yandex.ru/info'

# social-django
AUTHENTICATION_BACKENDS = [
    'social_core.backends.yandex.YandexOAuth2',
    'django.contrib.auth.backends.ModelBackend',
]
LOGIN_URL = 'users:login'
LOGIN_REDIRECT_URL = 'catalog:catalog'
LOGOUT_URL = 'users:logout'

 SOCIAL_AUTH_URL_NAMESPACE = 'social'
 SOCIAL_AUTH_LOGIN_REDIRECT_URL = 'catalog:catalog'
 SOCIAL_AUTH_LOGIN_ERROR_URL = 'users:login'

 SOCIAL_AUTH_YANDEX_OAUTH2_KEY = ''
 SOCIAL_AUTH_YANDEX_OAUTH2_SECRET = ''
 SOCIAL_AUTH_YANDEX_OAUTH2_EXTRA_DATA = ['refresh_token', 'refresh_token']

 SOCIAL_AUTH_PIPELINE = (
     'social_core.pipeline.social_auth.social_details',
     'social_core.pipeline.social_auth.social_uid',
     'social_core.pipeline.social_auth.auth_allowed',
     'social_core.pipeline.social_auth.social_user',
     'social_core.pipeline.user.get_username',
     'social_core.pipeline.user.create_user',
     'social_core.pipeline.social_auth.associate_user',
     'social_core.pipeline.social_auth.load_extra_data',
     'social_core.pipeline.user.user_details',
     'coffee_shop.apps.users.pipeline.set_yandex_id',
 )
```

Добавить в `INSTALLED_APPS`:
- `'social_django'`

Добавить в `TEMPLATES` context_processors:
- `'social_django.context.backends'` (если нужно)

### 3. Custom Pipeline Step
**Новый файл:** `django/coffee_shop/apps/users/pipeline.py`
- Функция `set_yandex_id` — сохраняет `yandex_id` в `social_auth` как доп. данные и создаёт `PersonalDataConsent` запись для пользователей, вошедших через OAuth.

### 4. Views
**Файл:** `django/coffee_shop/apps/users/views.py`
- Добавить view для обработки ошибок OAuth (опционально, social-django уже обрабатывает основные кейсы).
- Если нужно — кастомный callback для post-oauth логики (создание PersonalDataConsent и т.д.).

### 5. URL routing
**Файл:** `django/coffee_shop/apps/users/urls.py`
- Добавить: `path('oauth/', include('social_django.urls', namespace='social'))`
- Имя: `users:social` (через namespace nesting)

### 6. Шаблоны
**Файл:** `django/coffee_shop/templates/users/login.html`
- Добавить кнопку "Войти через Яндекс" после формы логина:
```html
<div class="text-center mt-3">
    <a href="{% url 'users:social' 'yandex' %}" class="btn btn-outline-primary">
        🟡 Войти через Яндекс
    </a>
</div>
```

**Файл:** `django/coffee_shop/templates/users/register.html`
- Добавить кнопку "Зарегистрироваться через Яндекс" в футер формы.

### 7. Docker
**Файл:** `docker-compose.yml`
- Добавить переменные окружения в service `web` и `celery-worker`:
```yaml
- YANDEX_OAUTH_CLIENT_ID=${YANDEX_OAUTH_CLIENT_ID:-}
- YANDEX_OAUTH_CLIENT_SECRET=${YANDEX_OAUTH_CLIENT_SECRET:-}
```

### 8. Migrations
- Запустить `python manage.py makemigrations` и `python manage.py migrate` — пакет `social_django` создаст таблицы: `social_auth_association`, `social_auth_nonce`, `social_auth_userSocialAuth`, `social_auth_usersocialauth_extra_data`.

## Environment variables

Необходимые переменные:
- `YANDEX_OAUTH_CLIENT_ID` — Client ID из консоли Яндекс Developer
- `YANDEX_OAUTH_CLIENT_SECRET` — Client Secret из консоли Яндекс Developer
- `YANDEX_OAUTH_REDIRECT_URI` — URL callback (по умолчанию `http://localhost:8000/accounts/oauth/complete/yandex/`)

## Настройка в Яндекс Console

1. Создать приложение в [developer.tech.yandex.ru](https://developer.tech.yandex.ru/)
2. Включить "OAuth API for Yandex Account"
3. Получить Client ID и Client Secret
4. Указать redirect URI: `http://localhost:8000/accounts/oauth/complete/yandex/` (dev)

## Авто-связка с существующими пользователями

При первом входе через OAuth:
- Если пользователь с таким email уже существует в БД — связать Яндекс-аккаунт с существующим User
- Если пользователя с таким email нет — создать нового пользователя
- В обоих случаях — создать запись `PersonalDataConsent` автоматически

## Верификация

1. `python manage.py migrate` — проверить создание таблиц social_django
2. Запустить dev-сервер: `python manage.py runserver`
3. Перейти на `/accounts/login/` — проверить наличие кнопки "Войти через Яндекс"
4. Нажать кнопку — перенаправление на Yandex OAuth
5. После успешного входа — пользователь создан/авторизован, создан PersonalDataConsent
6. Проверить, что существующие пользователи могут связать Яндекс-аккаунт с существующим профилем
