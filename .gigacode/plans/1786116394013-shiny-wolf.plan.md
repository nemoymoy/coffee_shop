# План доработок Coffee Shop (после анализа 1785963755950-witty-wolf.plan.md)

## P0 — КРИТИЧНОЕ (блокирует запуск)

### 1. Поправить Dockerfile ENTRYPOINT
**Файл:** `django/Dockerfile`
**Проблема:** `ENTRYPOINT ["sh", "../entrypoint.sh"]` — при `WORKDIR /app` путь `../entrypoint.sh` указывает на `..` (root of context), что неверно. При `COPY . .` файл копируется в `/app/entrypoint.sh`.
**Решение:** `ENTRYPOINT ["sh", "entrypoint.sh"]`

### 2. Поправить requirements/dev.txt
**Файл:** `requirements/dev.txt`
**Проблема:** Содержит только `pytest-django` без подключения base.txt
**Решение:** Добавить `-r base.txt` и dev-пакеты

### 3. Исправить migrations
**Проблема:** Файл `orders/migrations/0001_check_constraints.py` ссылается на таблицу, которая не создана миграцией
**Решение:** Переделать — создать базовую миграцию, добавить CHECK constraints туда

## P1 — ВАЖНОЕ

### 4. Баг refresh_token в yandex_oauth.py
**Файл:** `django/coffee_shop/apps/orders/services/yandex_oauth.py`
**Проблема 1:** В файле первый символ — `"` (лишняя кавычка), делает весь файл невалидным Python
**Проблема 2:** `self.refresh_token = data.get('refresh_token')` перезаписывает метод `refresh_token()`
**Решение:** Убрать лишний символ, переименовать атрибут в `_refresh_token`

### 5. Docker healthchecks
**Файл:** `docker-compose.yml`
**Проблема:** Нет healthcheck у redis, nginx, celery-worker
**Решение:** Добавить healthcheck для каждого сервиса

### 6. Rate limiting на Redis
**Файл:** `django/coffee_shop/middleware.py`
**Проблема:** `_requests = {}` на уровне класса — не работает при нескольких воркерах Gunicorn
**Решение:** Использовать Redis-хранилище
