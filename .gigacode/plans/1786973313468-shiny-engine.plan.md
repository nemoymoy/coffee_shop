# План: Интеграция Яндекс Доставки в оформление заказа

## Цель
Заменить простой textarea на кастомный модальный виджет Яндекс Доставки, где пользователь:
1. Выбирает тип доставки: курьер / ПВЗ / постомат
2. Вводит адрес с autocomplete через Яндекс Карты API
3. Видит расчёт стоимости и ETA
4. Данные возвращаются на страницу оформления заказа

---

## Архитектура

### Текущее состояние
- ✅ OAuth Yandex Delivery (yandex_oauth.py) — готов
- ✅ YandexDeliveryService — готов (mock-mode)
- ✅ `/checkout/calculate-delivery/` API — готов
- ✅ Модальные элементы в шаблоне — есть
- ❌ Нет frontend-виджета
- ❌ Нет Яндекс Карты API интеграции
- ❌ Нет UI выбора типа доставки (курьер/ПВЗ/постомат)

## OAuth Flow

1. **При открытии виджета** — проверить сессию на наличие токена
2. **Если токена нет** — показать кнопку "Подключить Яндекс Доставку", которая редиректит на `/delivery/auth/`
3. **После OAuth callback** — пользователь возвращается, виджет открывается
4. **Token refresh** — использовать `refresh_yandex_token_if_needed()` из `delivery_views.py`

---

## Расчёт стоимости

Используем текущий `/checkout/calculate-delivery/` API:
- Если есть токен → реальный вызов (fallback на mock)
- Если нет токена → показать заглушку 299 ₽

Дополнительные данные от виджета:
- `delivery_type`: courier / pvz / postomat
- `address`: структура с city, street, house, apartment
- `pvz_id` или `postomat_id`: если выбран пункт выдачи/постомат
