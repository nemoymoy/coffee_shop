# Исправление отображения карты Яндекс в модальной форме выбора доставки

## Проблема
При выборе способа доставки "Пункт выдачи (ПВЗ)" или "Постомат" в модальной форме не отображается карта Яндекс для выбора объекта.

## Анализ
1. Карта инициализируется в функции `initYandexMapForPvz()` при выборе типа доставки ПВЗ/Постомат
2. Изначально использовалось неправильное событие `ymaps3Ready`, которое не генерируется API
3. Затем была проблема с загрузкой компонентов через `ymaps3.YMapController` (not a constructor)
4. Затем проблема с `ymaps3.init is not a function`

## Диагностика

Из логов консоли браузера определены **доступные компоненты**:
- ✅ `YMap` - класс карты
- ✅ `YMapCollection` - коллекция маркеров
- ✅ `YMapMarker` - маркер (единичный)
- ✅ `YMapDefaultSchemeLayer` - слой схемы
- ❌ `YMapController` - **НЕТ в API**
- ❌ `YMapDefaultFeatureLayer` - **НЕТ в API**

## Решение

### Финальное решение: Прямое использование доступных компонентов

Переписана инициализация карты с использованием фактического API:

```javascript
// Создание карты через YMap
yamap.map = new YMap(mapContainer, {
    apiKey: getMapApiKey(),
    location: {
        center: currentCenter,
        zoom: 12
    }
});

// Добавление слоев
yamap.map.addLayer(new YMapDefaultSchemeLayer());

// Коллекция маркеров
yamap.collection = new YMapCollection(mapContainer, { components: 'points' });
yamap.map.addLayer(yamap.collection);

// Добавление маркера
yamap.collection.addItem({
    coordinates: [lat, lon],
    icon: '<div>...</div>',
    onClick: function() { ... }
});
```

## Проверка
Необходимо открыть консоль браузера и проверить:
- Лог `ymaps3 object keys` - покажет доступные компоненты
- Лог `Loaded components` - покажет какие компоненты загружены
- Лог `Using ymaps3.init()` или `Using ymaps3.ready()` - какой вариант использован
