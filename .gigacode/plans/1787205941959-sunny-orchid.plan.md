# Исправление отображения карты Яндекс в модальной форме выбора доставки

## Проблема
При выборе способа доставки "Пункт выдачи (ПВЗ)" или "Постомат" в модальной форме не отображается карта Яндекс для выбора объекта.

## Анализ
1. Карта инициализируется в функции `initYandexMapForPvz()` при выборе типа доставки ПВЗ/Постомат
2. Изначально использовалось неправильное событие `ymaps3Ready`, которое не генерируется API
3. Затем была проблема с загрузкой компонентов через `ymaps3.YMapController` (not a constructor)
4. Затем проблема с `ymaps3.init is not a function`

## Решение

### Этап 1: Исправлен polling загрузки ymaps3
- Заменено событие `ymaps3Ready` на polling каждые 100мс
- При обнаружении `ymaps3` вызывается `ymaps3.ready()`
- После готовности инициализируется карта для ПВЗ/Постомат

### Этап 2: Исправлена загрузка компонентов
- Заменён прямой доступ `ymaps3.YMapController` на `ymaps3.init()`
- Компоненты кэшируются в `yamap.components`

### Этап 3: Добавлена поддержка нескольких вариантов API (текущий)
Поскольку `ymaps3.init` может быть не функцией в некоторых версиях API, добавлена многовариантная загрузка:

1. **Вариант 1**: `ymaps3.init([components])` - с массивом компонентов
2. **Вариант 2**: `ymaps3.ready()` - возврат компонентов через ready
3. **Вариант 3 (fallback)**: Прямой доступ `ymaps3.YMapController`

## Проверка
Необходимо открыть консоль браузера и проверить:
- Лог `ymaps3 object keys` - покажет доступные компоненты
- Лог `Loaded components` - покажет какие компоненты загружены
- Лог `Using ymaps3.init()` или `Using ymaps3.ready()` - какой вариант использован
