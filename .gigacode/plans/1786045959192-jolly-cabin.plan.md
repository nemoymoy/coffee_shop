## Спринт 1: Критичный MVP (фронтенд + интеграции)

### 1.1 JavaScript-файлы (3 файла)
**Файлы:**
- `django/static/js/cart.js` — AJAX корзина (добавление, удаление, изменение количества)
- `django/static/js/coffee_selector.js` — выбор параметров кофе (вес, форма, способ заваривания)
- `django/static/js/checkout.js` — валидация формы checkout, автоподсчёт итогов
- `django/static/js/base.js` — общие утилиты (AJAX helper, форматирование)

**Реализация:**
- `cart.js`: AJAX POST к `/cart/add/`, `/cart/remove/<key>/`, `/cart/update/`; обновление UI без перезагрузки; обновление badge в navbar
- `coffee_selector.js`: пошаговый UI (вес → форма → способ заваривания); блокировка при stock=0; автопе��есчёт цены; валидация кратности 50
- `checkout.js`: валидация телефона (+7 формат), email; валидация адреса при delivery; debounce на полях

### 1.2 CSS-файлы (2 файла)
**Файлы:**
- `django/static/css/coffee_theme.css` — кофейная тема (цвета, карточки, типографика)
- `django/static/css/components.css` — кастомные компоненты (badge, карточки, модальные окна)

**Реализация:**
- `coffee_theme.css`: `$coffee-dark: #3E2723`, `$coffee-medium: #6D4C41`, `$coffee-light: #D7CCC8`, `$coffee-accent: #FF8F00`; адаптивная сетка; стили для product cards, cart items, checkout steps
- `components.css`: product card hover effects, coffee parameter selector UI, progress steps, table styles, badge colors для статусов заказов

### 1.3 Модальные страницы
**Файлы:**
- `django/coffee_shop/templates/dashboard.html` — личный кабинет
- `django/coffee_shop/templates/profile.html` — редактирование профиля
- `django/coffee_shop/templates/news.html` — новости и акции

**Реализация:**
- `dashboard.html`: история заказов (список с карточками), статусы с цветными бейджами, фильтрация по статусу
- `profile.html`: редактирование имени/телефона/email, сохранённые адреса (заглушка)
- `news.html`: список новостей с пагинацией (заглушка, если модели News нет)

### 1.4 Админ-панель: дополнительные действия
**Файлы:**
- `django/coffee_shop/apps/orders/admin.py` (модификация)
- `django/coffee_shop/apps/catalog/admin.py` (модификация)

**Реализация:**
- Экспорт заказов в CSV через Django admin action
- Массовое изменение статуса (new → in_progress, ready, cancelled)
- Статусные бейджи (admin_list_display_badges)
- Предпросмотр изображений в Product admin
- Фильтры: по статусу, категории, дате, наличию

## Верификация

1. `pytest tests/` — все тесты проходят
2. `python manage.py check --deploy` — security checks
3. `python manage.py makemigrations && python manage.py migrate` — миграции без ошибок
4. Запуск `docker compose up -d` — все контейнеры healthy
5. Postman/ curl тесты: /health/, /cart/add/, /checkout/, админка
6. Browser test: каталог → товар → корзина → checkout (полный флоу)
