# План запуска тестов проекта Coffee Shop

## Группы тестов:
1. **models** - тесты моделей (категории, заказы, товары, промокоды, отзывы)
2. **api** - тесты API (каталог, оплата, сериализаторы, Яндекс.Доставка)
3. **forms** - тесты форм (кофе, заказы, товары, пользователи)
4. **services** - тесты сервисов (корзина, кофе, доставка, ценообразование, остатки, пользователи)
5. **views** - тесты представлений (каталог, оформление, пользователи)
6. **news** - тесты новостного модуля (API, формы, модели, сервисы, views)

## Цели:
- Запустить каждую группу тестов по очереди
- По результату каждого теста предложить решение
- Проанализировать все результаты
