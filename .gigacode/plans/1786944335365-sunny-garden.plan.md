# Реализация Яндекс Доставки

## Контекст

Сервис `YandexDeliveryService` и `YandexOAuth` уже реализованы, но **не интегрированы** в пользовательский поток.
Не хватает UI, API-эндпоинтов и связки views с сервисом.

---

## План реализации (5 этапов)

### Этап 1: OAuth для Яндекс Доставки (auth flow)

**Цель:** Пользователь может авторизоваться через Яндекс и сохранить токен.

**Новые файлы:**
- `django/coffee_shop/apps/orders/views/delivery.py` — views для OAuth flow
- `django/coffee_shop/apps/orders/services/yandex_delivery_views.py` — helper для обновления токенов

**Изменения:**
- `django/coffee_shop/apps/orders/urls.py` — добавить routes:
  - `GET  /delivery/auth/` — редирект на Yandex OAuth
  - `GET  /delivery/callback/` — callback после авторизации, обмен кода на токен
  - Сохранение access_token и refresh_token в сессию пользователя

### Этап 2: API для расчёта стоимости доставки

**Цель:** Клиент может рассчитать стоимость и ETA перед оформлением заказа.

**Новые файлы:**
- Нет (добавить в существующий `django/coffee_shop/apps/orders/views.py` или создать `django/coffee_shop/apps/orders/api_views.py`)

**API-эндпоинт:**
- `POST /checkout/calculate-delivery/` — AJAX, принимает JSON с адресом, возвращает цену и ETA

**Изменения:**
- `django/coffee_shop/apps/orders/views.py` — добавить view `calculate_delivery_view`
- `django/coffee_shop/apps/orders/urls.py` — добавить route
- Вызывает `YandexDeliveryService.calculate_price(address)` с сохранённым в сессии токеном

### Этап 3: Интеграция в чекаут (UI + JS)

**Цель:** Пользователь видит стоимость и ETA доставки на странице оформления.

**Изменения:**
- `django/coffee_shop/templates/checkout.html` — добавить блок с информацией о доставке (цена + ETA), показывать при выборе "Доставка"
- `django/static/js/checkout.js` — при изменении radio "Доставка", делать debounced AJAX-запрос к `/checkout/calculate-delivery/`, показывать результат

### Этап 4: Создание заказа в Яндекс Доставке при оформлении

**Цель:** При сабмите формы с `delivery_method='delivery'` создаётся заказ в Яндекс Доставке.

**Изменения:**
- `django/coffee_shop/apps/orders/views.py` — в `checkout_view` после создания `Order`:
  - Если `delivery_method == 'delivery'`, вызвать `YandexDeliveryService.create_delivery_order()`
  - Сохранить `yandex_order_id`, `tracking_number`, `delivery_cost` в Order
  - Установить `status = 'in_progress'`
- `django/coffee_shop/templates/order_success.html` — показать tracking-номер и ETA
- `django/coffee_shop/apps/orders/models/order.py` — убедиться, что все поля присутствуют (уже есть)

### Этап 5: Синхронизация статусов (Celery task)

**Цель:** Реальная проверка статусов доставки каждые 5 минут.

**Изменения:**
- `django/coffee_shop/tasks.py` — реализовать `sync_yandex_delivery_status`:
  - Получить заказы с `yandex_order_id` и статусами `in_progress` / `ready`
  - Для каждого вызвать `YandexDeliveryService.get_delivery_status()`
  - Обновить `delivery_status` в Order
  - При статусе `delivered` → обновить `Order.status = 'delivered'`
