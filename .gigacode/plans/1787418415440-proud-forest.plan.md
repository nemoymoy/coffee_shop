# План рефакторинга checkout.js

## Анализ текущего состояния

### Обнаруженные проблемы

1. **Дублирование утилит** — `getCookie()`, `debounce()`, `parseAddress()` и `isValidEmail()` уже реализованы в `base.js` как методы `CoffeeShop`, но в `checkout.js` они переопределены локально.

2. **Несогласованность стилей** — `checkout.js` использует старый IIFE-паттерн с `var`, тогда как `cart.js` и `base.js` используют современный подход с объектом `CoffeeShop`.

3. **Отсутствует разделение ответственности** — функция `init()` содержит ~150 строк кода с множеством несвязанных задач: форматирование телефона, валидация email, расчёт доставки, переключение delivery method, интеграция с Yandex Widget, валидация submit.

4. **Неиспользуемая переменная** — `deliveryCalculationDebounced` объявлена, но никогда не используется.

5. **Неструктурированная обработка ошибок** — fallback значения '299 ₽' и '30-45 мин' захардкожены.

6. **Отсутствие констант** — URL эндпоинты, таймауты debounce, значения fallback — всё захардкожено в теле функций.

7. **Неоптимальная DOM-навигация** — repeated `document.getElementById()` вызовы без кэширования.

## Цели рефакторинга

1. Убрать дублирование кода, используя утилиты из `CoffeeShop`
2. Разделить `init()` на мелкие функции по ответственности
3. Вынести константы в начало файла
4. Добавить JSDoc комментарии для публичных функций
5. Привести стиль к единому с остальными JS-файлами проекта

## План изменений

### Шаг 1: Вынести константы в начало файла

Создать объект `CONFIG` с:
- `DELIVERY_CALCULATION_URL = '/checkout/calculate-delivery/'`
- `DELIVERY_CALCULATION_DEBOUNCE_MS = 1500`
- `DEFAULT_DELIVERY_PRICE = 299`
- `DEFAULT_DELIVERY_ETA = '30-45 мин'`
- `MIN_NAME_LENGTH = 2`
- `MIN_PHONE_DIGITS = 11`
- `YANDEX_WIDGET_OPEN_DELAY_MS = 200`
- `DELIVERY_SUMMARY_TYPES` — маппинг типов доставки

### Шаг 2: Убрать дублирование утилит

- Удалить локальные `getCookie()`, `debounce()`, `parseAddress()` — использовать `CoffeeShop.getCookie()`, `CoffeeShop.debounce()`, `CoffeeShop.parseAddress()`
- Оставить локальную `isValidEmail()` как приватную функцию (не дублируется в CoffeeShop)

### Шаг 3: Рефакторинг `init()` — разделение на методы

Разбить `init()` на отдельные приватные методы:

```
init()
├── _cacheElements()          — кэширование DOM-элементов
├── _initPhoneFormatting()    — форматирование телефона
├── _initEmailValidation()    — валидация email
├── _initAddressInput()       — обработка ввода адреса
├── _initDeliveryToggle()     — переключение способа доставки
├── _initYandexWidget()       — интеграция с виджетом
├── _initNameFields()         — валидация имени/фамилии
├── _initSubmitValidation()   — валидация перед отправкой
└── _initTotalDisplay()       — отображение итоговой суммы
```

### Шаг 4: Вынести `calculateDeliveryPrice()` в отдельный метод

Сделать приватным методом `_calculateDeliveryPrice()` с:
- Кэшированием timeout для debounce (в состоянии объекта)
- Удалением неиспользуемой переменной `deliveryCalculationDebounced`

### Шаг 5: Улучшить `updateDeliverySummary()`

- Использовать кэшированные DOM-элементы
- Вынести fallback значения в константы
- Убрать повторные запросы к DOM

### Шаг 6: Улучшить валидацию submit

- Добавить фокус на первое невалидное поле
- Использовать константы для сообщений
- Упростить логику проверки телефона
