# Миграция с SendGrid на RuSender

## Анализ

Проект использует SendGrid **только через SMTP** (`smtp.sendgrid.net:587` + TLS).
Пакет `sendgrid==6.10.0` в `requirements/base.txt` **не используется** ни в одном импорте — он остался как dead dependency.

Код отправки email в `tasks.py` использует стандартный Django `send_mail()` — никакой специфичной логики SendGrid нет.

### Найдено упоминаний SendGrid:
| Файл | Тип |
|------|-----|
| `django/coffee_shop/settings/base.py` | SMTP-конфиг |
| `django/coffee_shop/settings/prod.py` | SMTP-конфиг (дубликат) |
| `requirements/base.txt` | dead dependency |
| `README.md` | документация |

### Тесты:
Тесты email не написаны. Изменения в тестах **не требуются**.

## Изменения

### 1. `django/coffee_shop/settings/base.py` (строки ~145-155)

**Было:**
```python
if DEBUG:
    EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
else:
    EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
    EMAIL_HOST = 'smtp.sendgrid.net'
    EMAIL_PORT = 587
    EMAIL_USE_TLS = True
    EMAIL_HOST_USER = os.environ.get('SENDGRID_USERNAME', 'apikey')
    EMAIL_HOST_PASSWORD = os.environ.get('SENDGRID_PASSWORD', '')
```

**Стало:**
```python
if DEBUG:
    EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
else:
    EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
    EMAIL_HOST = 'smtp.rusender.ru'
    EMAIL_PORT = 465
    EMAIL_USE_SSL = True
    EMAIL_HOST_USER = os.environ.get('RUSENDER_USERNAME', '')
    EMAIL_HOST_PASSWORD = os.environ.get('RUSENDER_PASSWORD', '')
```

Ключевые отличия: порт `465` + `EMAIL_USE_SSL=True` вместо `587` + `EMAIL_USE_TLS=True`.

## Переменные окружения

Новые переменные:
```bash
# Email (RuSender)
RUSENDER_USERNAME=your-rusender-email
RUSENDER_PASSWORD=your-rusender-password
EMAIL_FROM=noreply@yourdomain.com
```

Старые переменные (`SENDGRID_USERNAME`, `SENDGRID_PASSWORD`) — больше не используются.

## Верификация

1. **Синтаксис:** `python django/manage.py check --deploy` (или `python manage.py check`)
2. **Тесты:** `cd django && pytest` — все существующие тесты должны пройти
3. **Импорт settings:** `python manage.py shell -c "from django.conf import settings; print(settings.EMAIL_HOST)"` — должен вывести `smtp.rusender.ru`
4. **В dev-режиме** — используется `console.EmailBackend`, ничего не сломается
