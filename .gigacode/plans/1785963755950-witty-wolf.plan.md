# План разработки: Сайт кофейни с магазином

## Стек и решения
- **Backend:** Django 4.2 LTS + Python 3.12
- **Frontend:** Django шаблоны + Bootstrap 5
- **API:** DRF (для интеграций + фронд)
- **БД:** PostgreSQL 15 (через docker)
- **Кэш/брокер:** Redis
- **Фоновые задачи:** Celery
- **Обработка изображений:** Pillow
- **Оплата:** ЮКасса
- **Доставка:** Яндекс Доставка (OAuth 2.0)
- **HTTPS:** Nginx + Certbot (Let's Encrypt)
- **Развёртывание:** docker-compose (Ubuntu 22.04 LTS)
- **Telegram-бот:** ОТЛОЖЕНО → следующий спринт

## Этап 2: Модели данных

### 2.1 Category
- name (CharField, unique)
- slug (SlugField, unique)
- parent (ForeignKey → self, null, blank, для вложенности)
- order (IntegerField, default 0)
- is_active (BooleanField, default True)

### 2.2 Product
- name (CharField)
- slug (SlugField, unique)
- description (TextField)
- category (ForeignKey → Category)
- **product_type** (CharField, choices: coffee/non-coffee)
- price_per_50g (DecimalField, for coffee products) — цена за 50 граммов
- base_price (DecimalField, for non-coffee)
- stock (IntegerField, default 0)
- image (ImageField, upload_to='products/')
- is_available (BooleanField, default True)
- allow_grinding (BooleanField, default False)
- available_brewing_methods (JSONField, хранить код методов)
- allergens (TextField, blank)
- **coffee_type** (CharField, blank): сорт (сорта — арабика/робуста/микс, или конкретные сорта: бурбон, пача, тикум и т.д.)
- **roast_level** (CharField, blank): обжарка (light / medium / medium-dark / dark / dark-roast)
- **origin_region** (CharField, blank): регион (страна + конкретный регион/ферма/кооператив)
- **processing_method** (CharField, blank): обработка (natural / washed / honey / anaerobic и т.д.)
- **sca_score** (IntegerField, null, blank, validators: 0-100): рейтинг SCA
- **tasting_notes** (TextField, blank): характеристика (вкус/аромат — дескрипторы, тело, кислотность)
- created_at (DateTimeField, auto_now_add)
- updated_at (DateTimeField, auto_now)

### 2.3 Order
- user (ForeignKey → User, null, blank)
- status (CharField, choices: new/in_progress/ready/delivered/cancelled)
- total_amount (DecimalField)
- payment_method (CharField, choices: online/cash)
- delivery_method (CharField, choices: pickup/delivery)
- first_name, last_name, phone, email
- comment (TextField, blank)
- delivery_address (TextField, blank)
- delivery_date/time (DateTimeField, blank, null)
- yandex_order_id (CharField, blank, null)
- tracking_number (CharField, blank, null)
- delivery_status (CharField, blank, null)
- delivery_cost (DecimalField, default 0)
- created_at, updated_at

### 2.4 OrderItem
- order (ForeignKey → Order)
- product (ForeignKey → Product)
- quantity (IntegerField)
- unit_price (DecimalField)
- **coffee_weight_grams** (IntegerField, blank, null)
- **coffee_form** (CharField, choices: beans/ground, blank, null)
- **brewing_method** (CharField, blank, null)
- created_at

### 2.5 PromoCode
- code (CharField, unique)
- discount_type (CharField, choices: percent/fixed)
- discount_value (DecimalField)
- max_uses (IntegerField, default 0 = безлимит)
- used_count (IntegerField, default 0)
- valid_from, valid_to (DateTimeField)
- is_active (BooleanField, default True)

### 2.6 Reviews (опционально)
- product (ForeignKey → Product)
- user (ForeignKey → User)
- rating (IntegerField, 1-5)
- comment (TextField)
- is_approved (BooleanField, default False)

### 2.7 Индексы и ограничения
- Индексы на slug, category_id, status, price, stock
- CHECK constraints для weight % 50 = 0 (кратность 50 г)
- CHECK для brewing_method NOT NULL WHEN coffee_form = ground
- INDEX на stock (для фильтрации)

## Этап 4: Бизнес-логика

- CartForm — проверка доступного количества

### 4.3 Мидлвари
- Rate limiting для форм заказа

- CSRF protection (включено)

### 4.4 Celery-задачи
- `tasks.py`:

## Этап 5: Фронтенд (Django Templates + Bootstrap 5)

### 5.1 Базовый шаблон
- `base.html` — layout с navbar, footer, breadcrumbs
- `base_without_nav.html` — для checkout-страниц
- Bootstrap 5 CDN + custom CSS
- Тёплая цветовая схема (кофейные оттенки)

### 5.2 Страницы
- **home.html** — баннер, УТП, хиты продаж, акции
- **catalog.html** — каталог с фильтрами (категория, цена, сорт, обжарка, регион, SCA) и сортировкой
- **product_detail.html** — карточка товара с выбором параметров кофе, информация о сорте/обжарке/регионе/SCA
- **cart.html** — корзина, промокод, выбор способа получения
- **checkout.html** — оформление заказа
- **about.html** — о кофейне, контакты, карта
- **news.html** — новости и акции
- **order_success.html** — подтверждение заказа
- **dashboard.html** — личный кабинет (история заказов)
- **profile.html** — управление профилем, адреса, избранное

### 5.3 Карточка товара — детали
- Фотогалерея
- Информация о кофе (для coffee products):
  - Сорт, обжарка, регион, обработка
  - SCA score (визуальный индикатор)
  - tasting_notes (вкус/аромат — дескрипторы, тело, кислотность)
- Блок выбора параметров (с визуальным разделением):
  1. Шаг 1: вес (кратен 50 г)
  2. Шаг 2: форма (в зёрнах / молотый)
  3. Шаг 3: способ заваривания (ТОЛЬКО если молотый)
- JS-валидация в реальном времени
- Отображение остатка
- Блокировка если stock <= 0
- Автопересчёт цены при изменении веса

### 5.4 JavaScript
- `cart.js` — AJAX для добавления/удаления из корзины
- `coffee_selector.js` — выбор параметров кофе
- `checkout.js` — валидация формы, интеграция с API Яндекс Доставки
- `delivery_calc.js` — расчёт стоимости доставки (через API)
